Feature 1 — Google Auth + Gmail Scanner

✅

Recommended: Google OAuth 2.0 + Gmail API

User clicks "Sign in with Google" → Google OAuth popup → server exchanges code for tokens → Gmail API fetches last 90 days of emails matching financial patterns → Claude extracts merchant + amount + date from each → merged into transaction feed alongside Plaid.

  • Auth: passport-google-oauth20 on Express, tokens stored in-memory
  • Gmail scope: gmail.readonly — read only, no send
  • Extraction: Claude Vision/text API reads email body → returns structured JSON
  • Email filters: subject keywords — "order", "receipt", "payment", "charged", "invoice", "statement"

Feature 2 — Smart Receipt Splitter

✅

Recommended: Claude Vision OCR + In-Memory Split Tracking

User uploads receipt image → sent to Claude claude-sonnet-4-20250514 with vision → returns structured line items + total → user enters group member names → picks split mode (equal / item-based / AI) → Claude calculates split → summary shown + stored in-memory with paid/unpaid tracking.

  • OCR: Claude Vision (no extra API key, handles messy receipts beautifully)
  • Storage: In-memory splits map on server (hackathon scope) + localStorage backup on client
  • Split modes: Equal (math), Item-based (user assigns items), AI (Claude recommends)
  • Tracking: Mark members as paid, see running "still owed" total

⚠️ What's NOT included (YAGNI)

  • No persistent database — in-memory only, fine for hackathon
  • No real payment links (Venmo/PayPal) — just amounts shown
  • No email notifications to split members
  • No multi-device sync
  • Gmail only scans financial emails — not full inbox
